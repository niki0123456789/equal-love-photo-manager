# =LOVE 生写真管理（参考版）

## 使い方
- `index.html` をブラウザで開くと動作します。
- メンバー、カテゴリ、発売順を切り替えられます。
- ヨリ・ヒキ・チュウの所持枚数を増減できます。
- 所持枚数はブラウザの LocalStorage に保存されます。
- 公式URLが登録されているイベントは公式ページを開けます。

## GitHub Pages
1. GitHubで新しいリポジトリを作成
2. `index.html` をアップロード
3. Settings → Pages
4. Deploy from a branch → main / root を選択
